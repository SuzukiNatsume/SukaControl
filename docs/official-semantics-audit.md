# 官方接口语义核对

适用范围：本机 Redmi G Pro 2024 / TM2211，已提取的 Xiaomi G Command Center 2.1.1.413 前端与 B21 原生接口。以下区分接口核对、控制器回读与肉眼验收；命令发送成功不等于效果已正确。

## 灯光接口

| 项目 | 官方语义及本机验证 | SukaControl 处理 |
|---|---|---|
| 三个灯区开关 | `GetKbdAreaStatus` / `SetKbdAreaStatus`：键盘位 0/1，Logo 位 5，Cover 位 4 | 键盘掩码 `03`，顶部 Logo `20`，光带 `10`。修复此前 Logo/光带开关位接反，控制和回读共用映射 |
| Logo 独立模式 | selector 0；通用标志位 6..7：0 跟随键盘、1 独立、2 跟随光带 | 按同一规则写入、回读；联动时禁用独立颜色 |
| 光带独立模式 | selector 1；通用标志位 2：0 跟随键盘、1 独立 | 按同一规则写入、回读 |
| 硬件键盘效果 | Wave 1、Breath 2、Wavelet 3、Trigger 5、ColorWave 6、Rainbow 7、Snake 8、FireFly 10、KeepOn 11 | UI 的常亮代码 9 转控制器 11。以上九个模式均重新做了控制器模式回读检查；不把软件效果映射成硬件常亮 |
| 逐键实时模式 | `B21PayloadWriter::SetRealMode`（`1801254e0`）读取通用设置，把报文偏移 5 设为 0；不是 FF | 三种软件效果先进入模式 0，并确认回读。FF 不能代替实时模式；持续输出期间检查实际模式仍为 0 |
| 逐键颜色 | `SetCustomeKeyboardColor`（`180124500`）：命令 04，每包最多 12 个 `{行×17+列,7F,R/2,G/2,B/2}`，不满包以 FF 终止 | 保留同一格式。连续帧内容变化与实时模式分别验证，不用选框文字当作硬件状态 |
| 实时亮度 | 本机进入模式 0 后通用回读亮度为 3；不同于普通硬件效果的亮度字段 | 软件亮度作用于像素颜色强度；界面同时考虑实际硬件亮度，不把进入模式后的 3 强制覆盖为用户所选软件亮度 |
| 普通键盘参数与自定义颜色 | 通用命令 02；普通参数路径与 `color_type=FF` 自定义颜色路径的更新范围不同。FF 颜色路径不能用于确认新的亮度已应用 | 先写普通参数并确认模式/亮度，再单独写支持的自定义颜色并确认 RGB。常亮、呼吸支持该单色路径；其他模式不开放无效的单色控件 |
| 顶灯/光带效果 | 命令 0C 查询、0D 设置；常亮 1、呼吸 2、渐变 3；颜色命令 0B，查询 0A | 两个区域分别查询模式和颜色；颜色写入后校验回读。RGB 使用官方报文的完整字节范围；环境光导致的观感偏色不能作为改动数值范围的依据 |
| 顶灯/光带颜色格式 | `SetCoverLogoEffect`（`1801234c0`）：Logo 为单条记录，光带为三条记录；强度字段 7F，RGB 字节不在此编码函数中减半 | 两个区域分别编码。顶灯开启、纯红色变化已获用户实际确认；白色偏蓝经用户说明为环境光影响 |
| 应用 | 官方有设置效果和保存效果两条调用，不应把设置自动等同于闪存保存 | 按用户要求，应用作为预览，按钮随后禁用；参数变化恢复可用。关闭灯区时所有该区域参数和应用按钮禁用 |
| 保存 | `SaveEffectParams`（`180123350`）单独发送命令 05 空载荷；普通参数选择字节 1 不是保存指令 | 只在明确保存时发送。软件效果先停止并恢复实际硬件备用效果，保存后恢复软件运行；失败也恢复软件运行。BIOS/掉电保留仍需实机重启验收 |
| 关窗、退出 | 不能把用户要求的预览生命周期宣称为官方默认行为 | 关窗撤销未保存预览；已保存软件效果在托盘继续运行；彻底退出停止软件效果。该行为是 SukaControl 的明确设计 |

本次检查全程保留测试前快照，结束恢复；不自动重启。控制器保存确认不等同于已完成冷启动测试。

## 其他已有功能的接口边界

以下核对接口定义，不要求用户重复此前已经验收的按键或性能测试。

| 功能 | 当前语义 |
|---|---|
| 四档性能 | MICommonInterface 命令 08；1 平衡、2 安静、3 高性能、4 全速；切换后读取真实档位。启动恢复与插电自动全速是本程序独立的可选策略 |
| 监控 | 命令 09 提供本机私有 CPU 温度/双风扇；CPU/RAM 和 NVIDIA 指标使用系统/显卡接口，不把无效读数当零 |
| Fn/Win Lock | 命令 0A，子功能 1/2；设置后回读。Fn+Esc、F10、Fn+K 的固件原生动作只同步状态，不再额外执行一次 |
| F7/F8 与其他快捷键 | F7 自定义、F8 打开 SukaControl，以及投影/设置动作由会话程序执行；Fn Lock 开启时尊重标准功能键语义。普通 K 不模拟 Fn+K |
| 屏幕响应加速 | 命令 0A 子功能 6，并回读；与刷新率、HDR、色温不是同一开关 |
| 独显直连 | 命令 0B 查询/设置 BIOS IGDS；读取固件状态，不用上次 UI 选择冒充实际状态；重启后才改变输出路径 |
| 护眼、ICC | 护眼是本程序的显示 Gamma 实现，受 HDR/驱动限制；ICC 使用系统色彩管理接口。二者不宣称复刻官方内部实现。已有 ICC 文件的保留和安装所有权规则不变 |
| 托盘、自启动、语言、安装/卸载 | 属于本程序实现；仅开机自启隐藏窗口，正常启动显示窗口；不依赖官方服务。未对已通过的卸载/ICC 测试重复操作 |
