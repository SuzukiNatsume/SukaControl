# SukaControl

面向 **Redmi G Pro 2024 / Windows 11 x64** 的独立控制台。目前的固件协议只适配这一型号，不会对未适配型号发送控制命令。

## 安装和使用

运行 `dist/SukaControl-Setup-0.2.8.exe`。安装后台服务时需要一次管理员确认；日常界面以普通权限运行，切换性能无需反复确认，也不会修改 Windows UAC 设置。安装包包含运行环境，无需另装 .NET。

在开始菜单打开 SukaControl。关闭主窗口会保留通知区域图标；从图标菜单选择退出才会结束程序。界面跟随 Windows 显示语言和深浅主题，支持简体中文、繁体中文、英文、日文。

提供四档性能模式、CPU/GPU/内存和温度风扇监控、独显直连/混合模式、屏幕响应加速、Fn 锁、Win 键锁、F7 操作自定义、护眼和 SDR ICC 色彩配置切换。

Fn Lock 开启时，固件将顶排作为普通 F1～F12 使用，程序不拦截。关闭时，F6 打开投影、F7 默认打开 Copilot、F8 打开 SukaControl、F9 打开系统设置，F10 逐档调节背光。Fn+Esc 切换和 F10 调光由固件原生处理，服务只同步状态，不重复执行。服务接收固件事件后，通过普通用户权限的会话桥接打开界面；因此退出控制台后，快捷键仍可工作。Fn Lock 开关与键盘亮度持续跟随实际状态更新。

窗口、快捷方式和安装器使用蓝色控制图标；托盘使用透明底单色图标，跟随任务栏的深浅主题。界面移除了不必要的小字说明。

键盘提供屏幕同步、音频同步、柔光、彩虹螺旋、按键响应、涟漪、色彩波浪、萤火虫、贪吃蛇、波浪、呼吸、常亮共 12 种样式。顶部标志灯与前侧灯带可独立设置，也可联动。屏幕/音频同步及柔光需要 SukaControl 运行；屏幕内容仅在内存中取色，不保存或上传。

独显直连切换需要重启。程序不会因切换模式而直接重启，用户必须另行确认重启操作。实际重启切换仍需在本机完成验收。

## 色彩与卸载

安装前已存在的 ICC/ICM 文件不归程序所有，卸载时保留。本机现有全部色彩文件已记录校验值并备份至 `backup/color-final`。

安装时缺少的三个小米 ICC 会记录归属及 SHA-256；升级保留归属记录。卸载只删除由本程序新增且内容仍未改变的文件。用户替换过的同名文件会保留。程序切换颜色前保存原有用户关联，恢复及卸载时还原该关联。

在 Windows 设置的“已安装的应用”中卸载 SukaControl，卸载需要管理员确认。卸载会移除程序目录、后台服务、用户设置、日志、开始菜单快捷方式、自启动和卸载登记。最后的运行中文件由退出后的清理进程删除。开发工作区、用户下载的安装包和 Windows 自身的历史记录不属于已安装程序的文件，不会被卸载器删除。

护眼通过显卡 Gamma 调整色温，退出时还原。0～100 的色温范围遵守 Windows Gamma 可读性限制；拖动滑条时合并连续更新，避免过密调用驱动。最大值已完成实机回读并恢复原曲线。HDR 或其他色温工具仍可能限制 Gamma；ICC 接口针对 SDR 显示配置。硬件控制不依赖小米官方应用、服务或其 DLL。Windows Update 管理的固件和显示器驱动可正常保留。

## 构建和验证

安装 .NET SDK 10，运行 `./build.ps1`。使用 Windows 自带的 .NET Framework 编译器生成安装器。

`dist/SukaControl/SukaControl.exe --selftest` 验证协议边界、语言选择和 ICC 归属规则；`--validate` 会在实机可逆地切换硬件设置并恢复原值，结果写入同目录 `validation.json`，因此不要对未验收的硬件运行。`--diagnose <输出路径>` 输出连接和传感器信息。

`research/validation-without-vendor.json` 为停用官方服务与相关驱动后的实机验证记录；`research/validation-after-vendor-uninstall.json` 为卸载官方软件后的验证记录；`research/uninstall-audit.json` 为真实卸载检查结果；`research/final-audit.json` 为最终文件与服务检查记录。F7 打开 Copilot、F8 打开 SukaControl 已由用户实体验收。独显直连仅验证同模式写入，重启后的实际模式变化仍需验收；当前显卡模式保持原样。

0.2.0 仅针对新改动验收：Fn+Esc 同步、两种 Fn Lock 下的按键语义由用户确认正常；`research/eye-limit-test.json` 记录最大色温的实机回读和原曲线恢复；`research/release-0.2.0.json` 记录本次发布。没有重新执行已通过的其他硬件测试。可用 `--test-keys` 检查新事件和服务请求边界，用 `--test-eye-limit` 验证并还原最大色温。

这是尚未代码签名的版本；安装器可能显示未知发布者。没有绕过系统安全设置。

## 0.2.5 托盘启动与性能恢复

仅登录自启动使用专用 --startup 标记，直接创建隐藏窗口与托盘图标，不再先显示后隐藏；重复的自启动不会打开已有窗口。手动打开、快捷方式、F8 和托盘打开都会显示界面。旧 --tray 参数不再隐藏窗口。升级会修正已存在的自启动命令，同时保留原有启用/禁用状态。

SukaService 接收系统关机/重启通知，退出前读取并保存实际性能档位；日常实际档位变化也会保存检查点。下次服务启动先读取固件，仅当实际档位与记录不同时尝试恢复，并回读校验；恢复失败（如电池供电无法开启高档位）时尝试平衡模式并校验。若固件连平衡也拒绝，则保留错误日志，不声称切换成功。记录保存在受保护的 ProgramData/SukaControl/performance-state.json，卸载随服务数据一并清理。

性能恢复的 12 项故障场景测试使用模拟固件，不操作真实硬件；完整关机/重启仍需下一次实机启动验收，程序不会主动重启电脑。


## 0.2.6 可选性能自动化

Overview 的性能模式下新增两个独立开关，支持简繁英日：启动时恢复上次性能模式（默认开启，兼容既有行为），接通电源时自动全速（默认关闭）。设置由服务持久保存，关闭主界面仍有效。关闭恢复开关后下次启动不因历史记录切换档位，但继续保存实际状态供将来使用。

自动全速在插入电源、已插电时首次开启开关及接通电源启动时应用；两个开关同时开启且插电启动时自动全速优先。手动改档会保留，直到下次重新接通电源，不会循环强制全速；拔掉电源不主动改变档位。全速申请失败时尝试平衡并回读确认。配置保存在受保护的 ProgramData/SukaControl/performance-options.json，卸载随服务数据清理。

25 项性能恢复及自动化测试通过，本机已完成开关保存和插电状态下平衡→全速的可逆验证。真实拔插电源及完整关机重启仍待实机验收。


## 0.2.7 硬件背光写入修正

对照官方 B21 CommonSetting 编码（0x180192d80）发现普通键盘设置的报文第 4 字节为 1，旧实现错误地强制为 0，服务白名单也拒绝 1。已将普通硬件灯效及开关设置改为官方同样的参数，并允许经过验证的 0/1 两种路径。该修正直接作用于灯光控制器，不用 Windows 启动后强制点亮来替代 BIOS 阶段的保留。

实时屏幕/音频/柔光帧继续使用临时参数；软件逐键模式不会作为普通硬件预设写入，停止实时效果也不重复提交硬件预设。用户主动关闭灯光或设为零亮度仍被保留。软件实时效果本身仍需要桌面程序运行。

本机控制器已接受参数 1，键盘从 0 档恢复到 2 档，原硬件灯效、颜色及其他灯区标志保持不变；31 项自动化测试通过。BIOS 阶段能否保持仍需实际重启验收，当前回读不代表已完成掉电保留测试。


## 0.2.8 独立应用/保存与三种软件效果

每个灯区的应用按钮用于预览：点一次后变灰，提示保存；改变参数后重新启用。页面顶部的保存按钮保存当前所有已应用灯区。官方 B21PayloadWriter::SaveEffectParams 实际发送独立的 0x05 空载荷命令，现已补齐；0.2.7 仅修正普通设置参数，单靠参数修正并不等于已保存。关闭窗口收进托盘时只撤销未保存预览并恢复此前设置；已保存软件效果继续在托盘运行。彻底退出时才停止软件效果。

光影随行、光音视界、柔光作为三个独立选项提供，不使用 Live effects 统称。保存软件效果时，先为 BIOS 写入常亮备用效果并发送保存命令，再保存 Windows 软件效果参数、恢复软件效果运行；下次启动程序可恢复已保存的软件效果，收进托盘后继续运行，彻底退出时停止。逐键实时帧不会被当作开机硬件预设保存。

45 项自动化测试通过，应用后按钮变灰/保存提示/保存后重新启用/关窗恢复，以及软件效果预览/参数保存/保存后托盘继续运行/彻底退出回退均完成本机可逆验证。测试后的原硬件灯效及原软件设置已恢复。0x05 保存命令已取得控制器确认，但 BIOS 阶段仍需实际重启验收。


灯效、颜色、速度、方向及三个灯区开关均由服务完整回读，现有控件直接同步，不另设硬件状态栏；编辑中的字段暂保留草稿，应用/保存/取消后重新跟随回读。音频解析覆盖 PCM 8/16/24/32 位与浮点格式、多声道，低信号不再因为灯柱高度取整而全部熄灭。光音视界通过系统回环测试确认收到音频、计算出亮键并输出，用户也观察到调试时随音乐变化。


## 0.2.9 软件灯效同步修正

灯区关闭时应用按钮禁用。软件灯效运行时，控件显示当前已应用的软件效果，避免控制器回读的硬件备用效果将光音视界覆盖为 Static。保存时保留原硬件灯效作为开机备用设置，并独立保存软件参数；失败时恢复软件效果运行。保存成功后，开启灯区的应用按钮恢复可用。47 项自动化测试及本机关闭按钮、软件保存/托盘运行、音频回环与持续同步检查通过。BIOS 掉电保留仍待重启验收。
