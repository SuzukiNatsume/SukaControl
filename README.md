# SukaControl

面向 **Redmi G Pro 2024（TM2211）/ Windows 11 x64** 的独立硬件控制台。主界面为 SukaControl，后台服务为 SukaService，不依赖小米官方应用或服务；未适配型号不会发送控制命令。

## 安装

从 [最新 Release](https://github.com/SuzukiNatsume/SukaControl/releases/latest) 下载 `SukaControl-Setup-1.0.0.exe`。安装包包含运行环境，无需另装 .NET。安装或升级服务需要一次管理员确认；日常控制以普通用户运行，切换性能无需反复确认，不修改 UAC。安装器未签名。

版本统一由根目录 `Directory.Build.props` 定义。About、Windows 卸载登记、三个程序集、安装器文件属性、安装器清单、输出文件名和发布流程均使用这一来源；构建时校验组件版本一致。

## 功能

- 四档性能：平衡、安静、高性能、全速；Fn+K 切换并同步实际档位。启动恢复上次性能、接通电源自动全速为独立可选开关。
- CPU、GPU、内存、温度及双风扇监控；独显直连/混合模式与 BIOS 状态同步，变更后引导重启。
- 键盘、顶部标志灯、光带的硬件灯效、颜色、亮度及联动；三种独立软件效果：光影随行、光音视界、柔光。
- Fn Lock、Win Lock、F7 自定义；屏幕响应加速、护眼、显示器热插拔列表及 ICC 色彩配置切换。
- Windows 11 Mica 界面、单色托盘图标，跟随系统深浅主题及简体中文、繁体中文、英文、日文。

开机自启动仅进入托盘；其他方式启动显示窗口。关窗收进托盘，托盘菜单提供打开及退出。

## 快捷键

Fn Lock 开启时顶排为标准 F1～F12。关闭时：

| 按键 | 动作 |
|---|---|
| F6 | 系统投影 |
| F7 | 默认 Copilot，可自定义 |
| F8 | 打开 SukaControl |
| F9 | 系统设置 |
| F10 | 逐档调节键盘亮度 |
| Fn+Esc | 切换 Fn Lock 并同步开关 |
| Fn+K | 固件原生性能切换；普通 K 不触发 |

Fn+Esc、Fn+K、F10 已由固件处理，服务仅同步相应状态，避免重复切换。会话桥接独立运行，退出主界面后快捷键仍可使用。

## 灯光

应用用于预览，应用后按钮禁用并提示保存；参数改变或保存成功后恢复可用。保存提交已应用设置。关窗撤销未保存预览；保存的软件效果继续在托盘运行，彻底退出时停止。

实际硬件状态回读至原控件，不增设硬件值栏。只有硬件处于实时模式且软件输出运行时才显示对应的软件效果。模式不支持的颜色、速度、方向、音源控件置灰；关闭灯区后该区参数与应用按钮禁用。

控制器非易失保存使用独立命令；软件逐键帧不会作为 BIOS 灯效保存。软件效果保存时，保留此前硬件灯效作为开机备用效果。BIOS 阶段及掉电保留仍待实际重启验收，收到保存确认不能代替冷启动测试。

## ICC 与卸载

安装器包含三个小米 ICC。安装前已存在的文件不归本程序所有，卸载保留；安装时新增且卸载时内容未变的包内 ICC 才移除。个人校色文件不会作为本程序文件删除。

从 Windows 已安装应用中卸载，清理界面、服务、会话桥接、自启动、快捷方式及程序配置。仓库、手动保存的安装器及用户原有 ICC 不属于安装目录清理范围。

## 构建与验证

Windows、.NET 10 SDK：

```powershell
./build.ps1
dotnet run --project tests/SukaControl.Tests -c Release -p:NuGetAudit=false
```

构建输出至 `dist`。48 项自动化检查通过；此前已完成按键、灯光应用/保存/回滚、软件效果托盘运行、控件同步及卸载清理检查。用户实机确认光音视界持续随音乐变化，以及顶部标志灯开启、变红。物理显示器拔插、完整关机重启、电源拔插等尚未完成的验收不视为已通过。

更多细节见 [官方语义核对](docs/official-semantics-audit.md) 和 [Linux 移植评估](docs/linux-feasibility.md)。Linux 文档为工程评估，当前发布包仍为 Windows 程序。
